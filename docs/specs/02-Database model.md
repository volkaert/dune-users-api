Dans la base de données, on veut stocker les informations suivantes pour un user:
- tenantId (String)
- tenantUserId (String)
- insertedAt (UTC timestamp - with or without offset - of the insertion of the user in the database - set by the database, not the application)
- onboardedAt (UTC timestamp - with or without offset - of the onboarding)
- firstName
- lastName
- birthDate
- address: street, postalCode, city, countryCode
