Dans la base de données, on veut stocker les informations suivantes pour un user:
- tenantId (String)
- tenantUserId (String)
- createdAt (UTC timestamp - with or without offset - of the creation of the user in the database)
- onboardedAt (UTC timestamp - with or without offset - of the onboarding)
- firstName
- lastName
- birthDate
- address: street, postalCode, city, countryCode
